Changelog

Every change to ganit, newest first. Releases are git tags (all tags, GitHub releases); the source of this page is CHANGELOG.md.

v0.1.42026-10-21release ↗

  • A website (GitHub Pages, https://theyashsawarkar.github.io/ganit/): the README as a home page, the changelog, and architecture decision records (docs/adr/), built from these files by scripts/build-site.py; CI checks the site is up to date.

v0.1.32026-10-21release ↗

  • Documentation for open source: a logo and banner, a full README (features, install, usage, configuration, troubleshooting, the whole Vyom family), CONTRIBUTING, SECURITY and CODE_OF_CONDUCT, issue and pull request templates, and CI (compiles, checks plugin.toml and that every key is documented).

v0.1.22026-10-19release ↗

  • Opens at Vyom's shared panel size (Vyom 0.2.5) like every other tool: its own width/height are gone.

v0.1.12026-10-19release ↗

  • Keys are spelled out (Ctrl+Enter, Shift+Enter, Backspace) instead of symbols (⌃↵, ⇧↵, ⌫) in the footer and on rows and buttons.

v0.1.02026-10-19release ↗

  • First release, as its own repository: the calculator and converter. Replaces wofi-calc.sh (a prompt, then a second wofi for the result) in Vayu.
  • Answers as you type, through qalc (libqalculate): arithmetic, functions, percentages (18% of 3897, 3897 + 18%), units (5 ft 11 in to cm), currency (100 USD to INR, rates refreshed once a day), dates, bases.
  • Integer answers also show with separators, in hex and in binary.
  • Enter copies the answer; Ctrl+Enter copies expression = answer.
  • A history of the last 50 calculations; Enter on one puts it back in the box to build on.
